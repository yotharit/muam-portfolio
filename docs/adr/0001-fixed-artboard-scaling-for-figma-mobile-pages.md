# Fixed-artboard scaling for single-breakpoint Figma pages

Landing, Illustration, and Animation were each designed as a single 393×844 mobile Figma frame with no tablet/desktop counterpart. Rather than rebuilding them as fluid/reflowing CSS, we lay out each page's markup at fixed pixel coordinates matching the Figma frame (the "artboard") and scale the whole artboard uniformly via `transform: scale()` to fit the real viewport, clamped to roughly 0.85×–1.75× so it never becomes illegibly small or absurdly large. This preserves exact Figma fidelity cheaply and matches the site's other pages, at the cost of not using extra width on tablets/desktop (it shows a larger centered mockup instead of a reflowed layout). Revisit only if desktop traffic justifies a real desktop design for these pages.
